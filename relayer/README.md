# Zarklink Relayer

Zcash block header relay service — bridges Zcash block headers to the Starknet `ZcashRelay` contract.

## How It Works

The relayer polls the Zcash regtest node for new block headers and submits them to Starknet in batches. This enables on-chain verification of Zcash transactions (note inclusion proofs) without trusting the relayer.

## Running

```bash
# Development (uses tsx)
pnpm dev

# Production
pnpm build && pnpm start

# Via orchestrator
./scripts/start-devnet.sh --services
```

## Configuration

Loaded from `.env.devnet` (auto-generated by `start-devnet.sh`):

| Variable | Description |
|----------|-------------|
| `STARKNET_RPC_URL` | Starknet RPC endpoint |
| `ZCASH_RPC_URL` | Zcash RPC endpoint |
| `ZCASH_RELAY_CONTRACT` | ZcashRelay contract address |
| `RELAYER_PRIVATE_KEY` | Starknet account private key |
| `RELAY_POLL_INTERVAL_MS` | Polling interval (default: 5000) |
| `RELAY_BATCH_SIZE` | Headers per batch transaction (default: 10) |

## Architecture

```
zcashd (regtest)  →  zcash-client.ts  →  header-pipeline.ts  →  starknet-client.ts  →  ZcashRelay contract
     ↓                    ↓                     ↓                        ↓
  RPC: getblock     Parse headers        Batch & validate         submit_headers_batch()
```
