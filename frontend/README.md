# Zarklink Frontend

Next.js 16 web application for the Zarklink privacy-preserving bridge protocol.

## Tech Stack

- **Next.js 16.1.6** — App Router, Server Components
- **React 19** — UI framework
- **Tailwind CSS 4.2** — Styling
- **starknet.js 9.2.1** — Starknet SDK for contract interactions
- **lucide-react** — Icons

## Pages

| Route | Description |
|-------|-------------|
| `/` | Dashboard — bridge stats, relay status, vault pool overview |
| `/bridge` | Issue (ZEC → wZEC) and Redeem (wZEC → ZEC) with full TX display |
| `/vaults` | Vault registry browser — view registered vaults and collateral |
| `/relay` | Zcash header relay status — chain tip, finality, header count |

## Wallet Connection

Two modes are supported via the wallet connector dropdown in the navbar:

- **Devnet Mode** — Select from pre-funded starknet-devnet accounts. Each account shows its role (Deployer, Vault #1, Issuer, Redeemer, etc.) and mapped Zcash address.
- **Browser Mode** — Connect ArgentX or Braavos browser wallet extensions.

Click **Account Details** in the wallet dropdown to see:
- Full Starknet address (with copy button)
- Mapped Zcash shielded address (if assigned)
- Private key (devnet only)

## Development

```bash
# From the project root (pnpm workspace)
pnpm -C frontend dev        # Start dev server on port 3000
pnpm -C frontend build      # Production build
pnpm -C frontend lint        # Run ESLint

# Or use the orchestrator script
./scripts/start-devnet.sh --frontend
```

## Environment

The `frontend/.env.local` file is auto-generated by `start-devnet.sh` and contains:

- `NEXT_PUBLIC_STARKNET_RPC_URL` — Starknet RPC endpoint
- `NEXT_PUBLIC_BRIDGE_ADDRESS` — BridgeProtocol contract address
- `NEXT_PUBLIC_REGISTRY_ADDRESS` — VaultRegistry contract address
- `NEXT_PUBLIC_POOL_ADDRESS` — VaultPool contract address
- `NEXT_PUBLIC_RELAY_ADDRESS` — ZcashRelay contract address
- `NEXT_PUBLIC_WZEC_ADDRESS` — wZEC token contract address
- `NEXT_PUBLIC_DEVNET_ACCOUNTS` — JSON array of devnet accounts with labels and Zcash address mappings
