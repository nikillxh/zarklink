# Zarklink CLI

Command-line tool for interacting with the Zarklink bridge.

## Usage

```bash
# Issue wZEC (lock ZEC → mint wZEC on Starknet)
pnpm cli issue --amount <ZEC> [--account <index>]

# Redeem wZEC (burn wZEC → unlock ZEC)
pnpm cli redeem --amount <ZEC> --address <zcash-shielded-addr> [--account <index>]

# Check vault status
pnpm cli vaults

# Query bridge state
pnpm cli status
```

## Running

```bash
# Development
pnpm dev -- <command> [options]

# Via pnpm workspace
pnpm --filter cli cli <command> [options]
```

## Commands

| Command | Description |
|---------|-------------|
| `issue` | Lock ZEC on Zcash, request wZEC minting on Starknet |
| `redeem` | Burn wZEC on Starknet, request ZEC unlock on Zcash |
| `vaults` | List registered vaults with collateral info |
| `status` | Show bridge contract state and pending requests |

## Configuration

Reads from `.env.devnet` (auto-generated by `start-devnet.sh`). Key variables:

| Variable | Description |
|----------|-------------|
| `STARKNET_RPC_URL` | Starknet RPC endpoint |
| `ZCASH_RPC_URL` | Zcash RPC endpoint |
| `BRIDGE_PROTOCOL_CONTRACT` | BridgeProtocol address |
| `ISSUER_PRIVATE_KEY` | Default issuer account key |
| `REDEEMER_PRIVATE_KEY` | Default redeemer account key |

## Dependencies

- **commander** — CLI argument parsing
- **starknet** — Starknet interaction (v9)
- **ora** — Terminal spinners
- **chalk** — Colored output
